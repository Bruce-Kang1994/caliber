# PM能力诊断工具 — 产品需求文档（PRD）

## 一、项目背景

### 1.1 问题起源

2026年3月，Bruce（5年产品经理经验，当前AI出海创业者）在创业半年后产生了一个疑问：

> "如果我现在去面试AI产品经理，结果会怎么样？我的能力到底怎么样？"

这个问题看似简单，却无法回答。因为：
- 产品经理的能力没有标准化的评估体系（不像工程师有LeetCode）
- 没有一个工具能告诉你"你的短板在哪里"
- 大多数PM对自己的能力认知存在系统性偏差（高估或低估）

### 1.2 用户验证：Bruce的真实案例

**用户画像：** 康鑫（Bruce），29岁，5年PM经验，天大软件工程本科 + 马来西亚理科大学CS硕士，当前AI出海创业中。

**经历了什么：**

| 步骤 | 过程 | 发现的问题 |
|------|------|----------|
| 口述经历 | Bruce描述自己的4段工作经历 | 把VIPKID售后系统重构（核心项目）说成了"CRM工具"（皮毛工作） |
| 简历拆解 | AI逐段分析简历中每段经历的核心价值 | 学术中国项目数据亮眼（转化率+57%），但Bruce自评"没有实质能力提升" |
| 矛盾发现 | 对比口述 vs 简历，发现3处重大矛盾 | Bruce在系统性地低估自己，用最弱的部分代表自己 |
| 能力评估 | 按13个维度逐项打分 | B端能力4.0分（长板），C端/商业化/自我表达1.5分（短板） |

**Bruce的反馈：**
- 最有价值的环节：能力评估框架（模块化PM能力）+ 经历拆解（跳出来看自己）
- 最不舒服的环节：被指出缺乏数据思维、经历不闭环
- 拿到结果后最想做的：补短板、深挖已有经历的价值
- 付费意愿：50元/月

### 1.3 核心洞察

通过Bruce的案例，提炼出3个关键洞察：

**洞察1：PM不是不优秀，而是不会"看见"自己的优秀**
Bruce的简历上有完整的数据和项目，但他自己聊的时候把80分的经历讲成了40分。这不是个例——大量PM存在"自我认知偏差"。

**洞察2：通用测评没有用，按目标岗位定制才有价值**
不同方向的PM（B端/C端/AI/增长），能力权重完全不同。通用问卷无法提供有针对性的诊断。

**洞察3：用户要的不是被打分，而是被"升级"**
"你缺乏数据思维"让人抵触；"你的业务拆解能力4.0分，加上数据验证习惯可以到4.5分"让人行动。同样的诊断结论，表达方式决定用户是否愿意付费。

## 二、产品定义

### 2.1 一句话描述

**基于AI的产品经理能力诊断工具：上传简历 → 按目标岗位定制评估 → 输出能力雷达图 + 经历价值挖掘 + 短板提升路径。**

### 2.2 目标用户

**主要用户：正在求职/转行的产品经理**
- 年龄：25-35岁
- 痛点：不知道自己什么水平、不知道短板在哪、简历不会写、面试不会讲
- 付费动机：强（求职有时间紧迫感）
- 使用场景：求职准备期（集中使用1-3个月）

**次要用户：AI产品经理（含转型中）**
- 痛点：AI PM能力没有评估标准、不知道和传统PM的差距在哪
- 付费动机：中等
- 使用场景：职业发展规划

### 2.3 核心场景优先级

| 优先级 | 场景 | 用户心理 | 产品功能 |
|--------|------|---------|---------|
| P0 | 求职备战 | "我要面试了，帮我准备" | 能力评估 + 短板诊断 |
| P1 | 职业发展 | "我想知道我什么水平" | 能力雷达图 + 提升路径 |
| P2 | 日常提升 | "帮我持续变强" | 能力追踪 + 学习推荐 |

### 2.4 核心差异点（vs 竞品）

| 竞品做法 | 我们的做法 | 为什么更好 |
|---------|----------|----------|
| 通用PM测评问卷 | 按目标岗位动态调整评估维度和权重 | 诊断结果更精准、更有行动价值 |
| 只输出分数 | 经历拆解 + 盲区发现 + 被低估的能力挖掘 | 帮用户"看见"自己看不到的东西 |
| 否定式反馈（"你哪里不行"） | 升级式反馈（"基于你的长板，如何补短板"） | 用户不抵触，愿意付费 |

## 三、MVP功能范围

### 3.1 用户旅程

```
Step 1: 选择目标岗位方向
        ↓
        用户选择：B端PM / C端PM / AI PM / 增长PM / 数据PM
        系统加载对应的评估维度和权重
        ↓
Step 2: 输入经历
        ↓
        方式A：上传简历PDF（AI自动解析）
        方式B：手动填写（引导式问答）
        ↓
Step 3: AI深度诊断
        ↓
        - 逐段拆解每段经历的核心价值
        - 发现用户的认知盲区（低估/遗漏的能力）
        - 按维度评分（详见评估框架文档）
        ↓
Step 4: 输出诊断报告
        ↓
        - 能力雷达图（可视化）
        - 每个维度的评分 + 评分依据
        - Top 3 长板（你应该放大的）
        - Top 3 短板（你应该补的）
        - 每个短板的具体提升建议
        ↓
Step 5: 行动引导
        ↓
        - "基于你的诊断，推荐你接下来做这3件事"
        - 引导到V2功能（提升内容、模拟面试）
```

### 3.2 MVP功能清单

| 功能 | 优先级 | 描述 | MVP是否包含 |
|------|--------|------|-----------|
| 目标岗位选择 | P0 | 用户选择想面试的PM方向 | ✅ |
| 简历上传与解析 | P0 | 支持PDF上传，AI自动提取结构化信息 | ✅ |
| 手动填写经历 | P0 | 引导式问答，帮助用户结构化描述经历 | ✅ |
| AI经历拆解 | P0 | 逐段分析每段经历的核心价值和盲区 | ✅ |
| 能力评分 | P0 | 按目标岗位的维度和权重打分 | ✅ |
| 诊断报告生成 | P0 | 雷达图 + 评分 + 长板/短板 + 提升建议 | ✅ |
| 报告分享 | P1 | 生成可分享的报告图片/链接 | ✅（简单版） |
| 用户账号体系 | P1 | 注册/登录，保存历史报告 | ❌（MVP不做） |
| 提升内容推荐 | P2 | 针对短板推荐文章/课程/练习 | ❌（V2） |
| 模拟面试 | P3 | AI扮演面试官进行模拟面试 | ❌（V3） |
| 能力追踪 | P3 | 多次评估对比，展示成长轨迹 | ❌（V3） |

### 3.3 MVP验收标准

一个用户从打开产品到拿到诊断报告，**全程不超过10分钟**。
报告质量标准：用户看完后能明确说出"我的长板是什么、短板是什么、下一步该做什么"。

## 四、商业模式（初步）

### 4.1 定价策略

| 市场 | 定价 | 依据 |
|------|------|------|
| 国内 | ¥50/月 或 ¥9.9/单次报告 | 用户验证反馈（Bruce付费意愿） |
| 海外 | $15-20/月 | 竞品参考（Exponent $12/月，面试工具$20-40/月） |

**建议：优先做海外市场（英文版）**，原因：
- 单价更高，更容易跑通商业模型
- 和PostMem的出海方向一致，能力复用
- 海外PM求职市场更成熟，付费意愿更强

### 4.2 获客策略（初步）

- 报告分享机制（"我的AI PM能力评分是82分"→社交传播）
- 个人品牌内容（Bruce自己的AI PM成长故事）
- PM社区投放（Product Hunt、LinkedIn、Reddit r/ProductManagement）

### 6.2 用户反馈原文

> **最有价值：** PM能力评估框架最有用，可以把产品经理的能力模块化；自己描述自己的工作经历有用，可以跳出来看自己究竟做过什么。
>
> **最不舒服：** 被指出缺乏数据思维，尤其是在VIPKID这样的大企业工作过，但自身收效甚微，显得经历不真实一样。
>
> **下一步行动：** 深度挖掘自己的工作经历，哪里缺经历、缺数据、不闭环就补充哪里。对于自己没做过的，就在现在的工作中快速做、打磨、提升。
>
> **付费意愿：** 50元人民币/月
